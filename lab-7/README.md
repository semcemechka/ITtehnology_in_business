# Практическая работа №7: Адаптивная вёрстка

**ФИО:** Судакова Мария Сергеевна  
**Группа:** ИСТ-37  
**Вариант:** 10 (SaaS-платформа TaskFlow)

## Описание
Адаптивная страница SaaS-платформы для управления проектами с:
- Desktop и Mobile версиями
- Ручным и автоматическим переключением видов
- CSS Grid для основных сеток
- Flexbox для навигации и кнопок

## Технологии
- HTML5
- CSS3 (Grid, Flexbox, Media Queries)
- JavaScript (переключение видов)

## Как проверить
1. Откройте страницу на компьютере
2. Нажмите кнопки Desktop/Mobile в шапке
3. Измените размер окна браузера (автоматическое переключение)
4. Откройте DevTools (F12) и переключитесь на мобильный вид
